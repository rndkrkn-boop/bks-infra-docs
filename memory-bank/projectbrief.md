# Project Brief

`nemohermes_bks` is the infrastructure and documentation workspace for the
БайкалКварцСамоцветы production agent platform. It combines separate repositories
for NemoClaw/OpenShell sandboxes, Hermes profiles, the LLM router, MemGraphRAG,
security policies, host supervision, monitoring, and deployment documentation.

The current task is a full evidence-based audit of the existing production
contour up to Gate 1. The audit must produce a repository/runtime drift report,
a requirements matrix, a risk register, and a formal Go, Conditional Go, or
No-Go decision. Phase 2–3 capabilities are tracked as future-readiness gaps and
do not automatically block the current production decision.

Audit evidence must never contain secret values. Existing unrelated workspace
files, including `IMG_text.jpg`, must remain untouched.
