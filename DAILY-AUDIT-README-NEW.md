## ✅ What Happens Step-by-Step

### Step 1: Daily Audit (10:00 AM - automatic)
```bash
# Cron runs this:
bash daily-audit-and-wait.sh

# What it does:
1. Claude analyzes code, security, tests, docs, architecture
2. Generates: audits/2026-08-05-audit-report.json
3. Sends: "Review audit and create approval file"
4. Waits: For you to create approval.json
5. DOES NOT PROCEED until you approve
```

### Step 2: User Approval (you, any time before bed)
```bash
# You create this file:
# /home/admin/projects/nemohermes_bks/audits/2026-08-05-approval.json
# (with selected issues to fix)
```

### Step 3: Immediate Implementation (auto-starts)
```bash
# Script: daily-implement-now.sh (auto-triggered by approval)
# What it does:
1. Reads your approval file
2. Creates Kanban board: kanban/2026-08-05-kanban.json
3. Sequential Loop for each approved issue:
   a) Claude reads issue details
   b) Claude implements with this prompt:
      "Create the files + TEST each file:
       - Run npm test / pytest
       - Run eslint / pylint (syntax)
       - Run yamllint (for YAML)
       - Verify files exist
       - Output summary"
   c) Tests run INLINE (while Claude works)
   d) Move to next task
4. When all tasks done → calls daily-verify-and-commit.sh
```

### Step 4: Final Verification & Auto-Commit
```bash
# Script: daily-verify-and-commit.sh (auto-runs after Step 3)
# What it does:
1. Full test suite: npm test, pytest
2. Code quality: eslint, pylint
3. Security: trivy, pip-audit
4. Health: docker-compose ps, health endpoints
5. Claude verification: sanity check
6. If ALL PASS → git commit (automatic)
7. If ANY FAIL → alert you + require manual fix
```

## 🎯 Claude Testing During Implementation

Each task includes embedded testing:

```
Claude Task Prompt:
─────────────────
Title: Add connection pooling

Implementation: Setup pgbouncer with 50 connection pool...

IMPORTANT: As you implement, include testing:
1. Create files/changes
2. For each file created, verify it exists: `ls -la FILE`
3. Run syntax checks:
   - Bash: `bash -n script.sh`
   - Python: `python -m py_compile file.py`
   - YAML: `yq . file.yaml` or `yamllint file.yaml`
4. Run unit tests: `npm test`, `pytest`
5. Output summary: what was created, what was tested, pass/fail

Result:
───────
Claude creates → Tests inline → Reports results → Next task
```

## ❓ FAQ

### Q: What if I don't approve any issues?
A: Script waits indefinitely. Next day at 10:00 new audit runs (yesterday's ignored).

### Q: Can I approve after work hours?
A: Yes! Approval anytime during the day. Implementation starts immediately whenever you create the file.

### Q: What if Claude hits max-turns?
A: Partial implementation. Verification might fail. Manual fix needed.

### Q: Can I run manually?
A: Yes!
```bash
# Run entire cycle
bash /home/admin/projects/nemohermes_bks/scripts/daily-audit-and-wait.sh

# Or just implement (requires approval.json to exist)
bash /home/admin/projects/nemohermes_bks/scripts/daily-implement-now.sh

# Or just verify/commit
bash /home/admin/projects/nemohermes_bks/scripts/daily-verify-and-commit.sh
```

### Q: What if tests fail in Phase 2?
A: Commit is skipped. Manual review + fix required. Then retry verification.

### Q: Timeline?
A: 
- Audit: 5-15 minutes (10:00 AM)
- Approval: 30 min - 8 hours (you create file anytime)
- Implementation: Depends on task complexity (can take 1-8 hours)
- Verification: 5-15 minutes (auto-runs)
- **Total:** Usually 2-4 hours for 3-5 tasks
